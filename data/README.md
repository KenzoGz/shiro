# Site data

- `site-copy.json` contains the editable homepage, About, and Fiction text, plus random status lines and thoughts.
- `assets.json` maps the shared images and GIF collection used by the page.
- `../content/projects/projects.json`, `../content/experiments/experiments.json`, and `../content/archive/archive.json` contain the entries for those apps.

The page fetches these JSON files directly, so preview it through a local web server or static host rather than opening `index.html` as a `file://` URL.
