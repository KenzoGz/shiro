# Projects

Add project entries to `projects.json`. The app reads this file directly, so no HTML edits are needed.

Each item can use these fields:

```json
{
  "title": "Project name",
  "summary": "A short description",
  "status": "In progress",
  "date": "2026",
  "tags": ["web", "javascript"],
  "url": "https://example.com"
}
```

Only `title` is required. Remove fields you do not need. Keep valid JSON commas and quotes.
